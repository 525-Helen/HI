CORE FEATURES

不止于记录，更是健康决策助手

把"今天吃得怎么样"变成可量化、可追踪、可预警的数据，而不是模糊的感觉。

🥗

饮食解析与热量打卡

将自然语言描述识别为结构化食物明细，逐项计算热量，颗粒度到单个菜品。

🧮

宏量营养分析

输出碳水 / 蛋白质 / 脂肪三大营养素构成，并给出对应的健康建议，帮助你吃得更均衡。

🎯

目标额度管理

支持减脂、维持体重、增肌三类目标，实时呈现"本餐完成度 + 今日剩余额度"。

⚠️

安全与过敏预警

叠加过敏源与高热量食品预警，主动规避风险食材并提供替代建议，守护饮食安全。

🧠

多轮对话记忆

Agent 具备滑动窗口短期记忆，能跨越多次对话记住你的偏好、忌口与历史记录。

🛡️

用户数据隔离

基于独立用户标识进行数据隔离与持久化，不同用户各有一份安全私密的记录空间。

HOW IT WORKS

一次打卡的智能工作流

从一句"我吃了…"到一份可执行反馈，卡卡在后台完成确定性计算与智能推理。

1

输入

用文字描述一餐食物，支持自然口语表达。

2

识别

智能解析为结构化食物明细与用量估计。

3

计算

确定性计算本餐热量与三大宏量营养并落库。

4

反馈

结合目标额度与安全规则，输出即时健康建议。

一份即时的营养报告

每次打卡后，卡卡会生成结构化的营养报告：热量、三大营养素、目标完成度，以及需要留意的安全提示。目标额度是确定性的，而非模糊估算。

全栈工程化沉淀
